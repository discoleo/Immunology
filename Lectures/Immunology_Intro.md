
# Immunology Lectures

## Lab Methods: PCR

The purpose of this lecture is to give medical/biology students and young researchers an idea about PCR, as well as to the possible applications of PCR.

It is **not** intended for technical assistants who actually run the PCR. Especially, the section on PCR primers should give young researchers insight how to design the primers and apply the PCR in new fields.

The melting temperatures were computed using the R scripts available at:
https://github.com/discoleo/R/blob/master/Chemistry/PCR.Examples.R
The actual functions are in:
https://github.com/discoleo/R/blob/master/Chemistry/PCR.R

I will update this lecture, as time permits.
